## 待评估

### 交互行为录制（--observe 模式）
- **提出**：2026-07-14 · 等待评估
- **说明**：针对用户有权研究的网页工具，录制可见浏览器中的交互（拖拽、点击、表单填写），提取 DOM 变化、CSS class 切换、事件类型和 Canvas API 调用，生成抽象的交互模式报告
- **场景**：理解公开交互模式，并在自己的产品中独立实现类似体验，不复制专有代码、内容或资产
- **技术路线**（待定）：A. nexpage --observe 模式，B. 独立 Playwright 录制脚本原型
- **实现量**：大 — MutationObserver + Event 劫持 + Canvas 代理 + 报告格式化

### 暗色模式提取
- **提出**：2026-07-14 · 等待评估
- **说明**：提取网站暗色主题的设计 token
- **实现量**：中等 — `crawlPage` 已支持 dark 参数，CLI 加一个 `--dark` flag 即可

### 多页面爬取
- **提出**：2026-07-14 · 等待评估
- **说明**：`nexpage <url> --depth 3` 自动发现内部链接并逐页提取
- **实现量**：大 — 需要重新连接 `multipage.js` 逻辑

### 批量提取
- **提出**：2026-07-14 · 等待评估
- **说明**：`nexpage urls.txt` 从文件读 URL 列表，逐个提取。每个网站弹出一次浏览器窗口
- **实现量**：小 — 循环读取 + 单个提取

### 设计对比
- **提出**：2026-07-14 · 等待评估
- **说明**：`nexpage diff <urlA> <urlB>` 两站对比，输出 diff markdown/html
- **实现量**：中等 — 需要重新连接 `diff.js` 逻辑

### 评分专用模式
- **提出**：2026-07-14 · 等待评估
- **说明**：`nexpage grade <url>` 只评分不生成文件，快速看一眼网站设计质量
- **实现量**：小 — 跳过文件生成步骤

### 输出格式选择
- **提出**：2026-07-14 · 等待评估
- **说明**：`nexpage <url> --format tailwind,figma` 只生成指定格式
- **实现量**：小 — 文件生成加白名单过滤

### 持久化会话
- **提出**：2026-07-14 · 等待评估
- **说明**：`nexpage <url> --session myapp` 保存浏览器登录态，下次同一 session 免登录
- **实现量**：中等 — Playwright storageState 支持
